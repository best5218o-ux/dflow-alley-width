# 산출물 명세 — `deliverables/` 전 파일

작성 2026-09-16 · **전면 개정 2026-09-18**(외부 감사 지적 반영) · 기준 문서 `docs/판정기준.md`(각 절 머리에 실행 전 커밋)
재현: 공개 데이터와 브이월드 API 만 사용, 상용 API 없음. 브이월드 인증키는 환경변수 `VWORLD_APIKEY` 로만 읽는다(`VWORLD_DOMAIN` 도 함께, README 참조).

이 문서는 **값을 고치지 않는다.** 값이 이상하거나 이름이 오해를 부르는 자리는 「읽을 때 조심할 것」에 적을 뿐이다.
행 수는 헤더를 뺀 데이터 행 수다. 「37조각」은 대전 진입곤란 지정 26개소를 도로명 조각으로 나눈 37개, 「26개소」는 그 개소 단위다.
「생성 스크립트 없음」은 두 저장소(공개·비공개) 어디에도 그 파일을 쓰는 코드가 없다는 뜻이다 — 손으로 만든 표이며, 재실행으로 재현되지 않는다.

## A. 핵심 사슬 — SAM 차량탐지 → 통행가능폭 (§34)

### `통행가능폭_주차차감_37조각.csv`
- 무엇: 조각별 최종 통행가능폭과 판정. 제출본이 말하는 **최종 판정은 이 파일의 「판정(최종채택)」**이다.
- 행·열: 37행 × 20열. 열: 시군구 · 조각 · 도로명 · road_bt · 확정차량수 · 횡점유중앙(m) · 횡점유최대(m) · W_pass(m) · SAM판정(W_worst) · 내접폭차감(m) · W_worst(m) · 최종채택(m) · 채택근거(둘중작은값) · 판정(최종채택) · 기존판정(내접폭) · 판정변화 · 비고 · 분리방식 · 일반차량_진입차단_필요 · 임계근거

- 조심할 것: `road_bt` 는 도로명주소도로의 폭 속성으로 **단위 미확인**(`이름은있는데쓸수없는속성.md`). 확정차량수 0 이면 W_worst 는 road_bt 그대로이며(「차량없음_road_bt적용」) 미탐 가능성이 비고에 적혀 있다. 최종채택이 빈 조각은 `UNKNOWN_FAIL_CLOSED`(같은 도로명 도로구간 없음 · road_bt 없음)이다.

### `회랑필터_전후_오탐.csv`

- 슬롯: `seconds` 는 26행 전부 `NOT_COMPUTED`. 시간은 `슬롯시간_26개소.csv`(1단계)에서 따로 낸다.
